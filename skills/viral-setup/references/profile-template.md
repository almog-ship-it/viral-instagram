# Profile template

Write `viral-instagram/profile.md` exactly in this shape. Every skill parses it by these headings.

```markdown
# Viral Instagram profile
updated: YYYY-MM-DD

## Account
handle: <username without @>
followers: <number>
reels_count: <number>
carousels_count: <number>
deep_insights: yes | no
language: <he | en | ...>

## Formats
- reels
- carousels

## Business
what: <one sentence>
audience: <who, and what hurts them>
market: <country and language of the content>
inferred_from: profile | answers
goal: <one or more of: followers, leads, sales>
cta: <what the viewer should do at the end>

## Voice
on_camera: <fast / calm / dry / funny ... or faceless>
words_i_use: <a few>
words_i_never_say: <a few>
emoji: never | rarely | freely
inferred_from: <links to the 3 posts the user picked, or "answers">

## My positions
- <a belief part of the audience disagrees with>

## Proof I can use
- <real number, outcome or story the user approved>

## Reference accounts
- <username>

## Won't do
- <item>

## Connections
instagram: active
niche_data: yes | no
apify: active | skipped
gmail: active | skipped
alert_email: <address or none>

## Trend alerts
frequency: weekly | biweekly | off
delivery: email | file
```
